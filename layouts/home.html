OPynSim brings native OpenSim-powered biomechanical simulation and visualization directly into a Python API that fits with the rest of your Python environment. It lets you move from model inspection/analysis to solvers and visualizers in a few lines of code (pip install opynsim).

Currently under construction 🚧. The API is expected to stabilize late-2027. It's currently mostly stable: you can install and use it already, but there may be some minor changes as we build it.

The OPynSim project also develops the Pragmatic Musculoskeletal Modelling handbook, which is an open education resource for learning the wider Python musculoskeletal modelling ecosystem.

Currently under construction 🚧. The content's already useful for small training seminars (we use it internally) but some guides are not fully written. We're also looking for other Python project developers that can contribute to the guide!
